# Verify claims

Verify consequential claims against primary evidence. Agent status, narrated intent, a successful tool response, and a verified external result are different facts. Scale verification to the claim; use the project’s installed engineering guidance for code, tests, and Git workflows.

Read [evidence and completion checks](references/evidence.md) when checking consequential claims before reporting them.
