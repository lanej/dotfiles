# Tool adoption: backfill

Apply the application tool catalog to new independent surfaces within the project’s authority and record the direction for migrating existing implementations. Read [the catalog](tool-catalog.md) when choosing tools for that work. Execute migration only within an explicitly agreed task scope, including compatibility and validation; ordinary feature work does not authorize a rewrite.

Apply this together with the installed authority reference. Adoption does not establish project agreement or waive repository requirements.
