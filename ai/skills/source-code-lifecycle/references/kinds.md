# Legacy project-kind selection

For an older directory-linked installation, read `kind` from the consuming repository's installed `.source-code.json`, then load only the matching [service](kind-service.md), [library](kind-library.md), or [tool](kind-tool.md) guidance. An omitted kind uses [unspecified-kind guidance](kind-unspecified.md). Missing or invalid policy preserves authored requirements and gates, grants no new authority, and does not justify inferring a kind; report invalid policy. Setup or upgrade replaces this selector with the selected guidance.
