# Tool adoption: new

Apply the application tool catalog to new independent surfaces within the project’s authority. Extend established surfaces using their existing stack; creating a file or endpoint inside one does not make it independent. Read [the catalog](tool-catalog.md) when the affected capability qualifies and project governance permits it. This setting does not authorize migrating existing implementations.

Apply this together with the installed authority reference. Adoption does not establish project agreement or waive repository requirements.
