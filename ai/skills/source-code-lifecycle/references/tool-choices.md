# Installed application tool policy

Before choosing application libraries, API protocols, or migration scope, read [the installed lifecycle entrypoint](../SKILL.md). It states this project’s selected authority and adoption policy. Preserve authored requirements, established interfaces, and the task’s authority. Follow the adoption guidance for using the application tool catalog when applicable.

These policies apply at the installed lifecycle stage and do not grant publication or unrelated migration authority. Use the source-code management skill to preview and apply changes to project policy.
