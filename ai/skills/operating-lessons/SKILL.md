# Operating lessons

Apply situational lessons for agent coordination, factual verification, tool authority, documents, and account access. Current user instructions and host capabilities control the procedure. Historical incident tool names are examples; do not assume those tools exist or that past approval authorizes a new action.

Read only the reference matching the current uncertainty:

- Read [delegation and verification](references/delegation.md) before accepting delegated factual claims, selecting an output contract, or coordinating dependent tasks and peer sessions. Verify consequential claims against observable results; status and narrated intent are not completion.
- Read [coordination and shared resources](references/coordination.md) before briefing agents with different tool capabilities, interpreting a changed decision, or managing task-owned processes. Preserve other sessions and their resources.
- Read [tools, documents, and accounts](references/technical.md) when checking argument handling, prompts, document consistency, scheduled-tool outcomes, internal search, or credential account selection.

This package does not supply source-code construction, testing, architecture, commit, PR, or merge policy. Use the repository’s explicitly installed project guidance for those tasks. Do not load coding lessons merely because an agent or tool is involved.

A missing historical memory citation does not establish a rule’s current authority. Follow current instructions, preserve the useful constraint when it still applies, and report a concrete verification gap when necessary.
