# Default software guidance: Builder

For software design, implementation, modification, debugging and review, use the project's explicitly selected repository-local Builder core when available; otherwise read `~/.local/share/software-standards/builder/SKILL.md`. That core retains the required software properties, architecture defaults and construction safeguards. Load full architecture/construction references by the task triggers in the core, rather than rereading all references for every edit.

Apply host instruction precedence and project constraints. Report unavailable guidance as a limitation; do not claim it was read. Passing installation checks, example checks or instruction compliance does not establish software compliance.
