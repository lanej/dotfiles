# Configured notification follow-up

Use the current notification’s state to read only the corresponding entry under `[notifications.instructions]` in `octo-manager.toml`. Follow that configured instruction within installed project guidance and the existing task’s authority. Do not substitute seed text, load instructions for unrelated states, or infer permission from receipt or acknowledgment.

Inspect full action evidence with the installed Octo CLI when needed to identify the state, pinned head, prerequisites, owner, and outstanding assessment. Use its current help for supported commands. If policy cannot be read, use Octo’s retained last-valid instructions when supplied; otherwise report the unresolved instruction rather than guessing. Preserve the distinction between delivery, acknowledgment, owner assessment, and resolution.
