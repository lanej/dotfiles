# Automation evidence and reconciliation

<!-- source-code:legacy-routing -->
Read [the installed merge default](auto-merge.md) for the repository default selected at setup. When handling a notification, read [the configured follow-up](notification-instructions.md) for its current state.
<!-- /source-code:legacy-routing -->

Follow an explicit per-PR override supplied by current Octo evidence; that override takes precedence over the repository default. Inspect the current action when an override or queued operation is unknown. Do not change a PR switch or restore inheritance without authorization. Keep readiness, queued operations, and verified merge outcomes distinct.

Use current notification and action evidence to identify the applicable configured follow-up. Preserve installed project guidance and existing task authority. Delivery and acknowledgment do not establish owner assessment or resolution.

Inspect reconciliation evidence before retrying an uncertain operation. Do not duplicate a queued merge or treat disabling automation as cancellation of already-submitted work. Report observed outcomes and remaining uncertainty.
