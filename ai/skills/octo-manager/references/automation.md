# Installed repository automation

Read the installed `references/auto-merge.md` in this skill package for the repository default selected at setup. Follow an explicit per-PR override supplied by current Octo evidence; that override takes precedence over this default. Inspect the current action when an override or queued operation is unknown. Do not change a PR switch or restore inheritance without authorization. Keep readiness, queued operations, and verified merge outcomes distinct.

When handling a notification, read [the configured follow-up](notification-instructions.md) for its current state. Preserve installed project guidance and existing task authority.
