# Agent coordination

Use the host’s supported coordination tools within the current task’s authority. Inspect capabilities before dispatch, return findings inline unless a file is useful and writable, and preserve other sessions. A peer’s agreement does not authorize an action. This skill does not impose a planning ceremony or project engineering policy.
