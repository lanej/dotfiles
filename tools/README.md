# Tools

Standalone tools developed alongside the dotfiles. Each tool owns its dependencies, build, checks, and usage instructions; placing a tool here does not install it automatically.

- [Pi GitHub worker](pi-github/): Bun-based Pi scheduler with a terminal dashboard, a Codex-facing CLI, public GitHub PR summaries, and a real merge-conflict demo. Includes a [state diagram](pi-github/README.md#scheduling-and-state) and a [live dashboard screenshot](pi-github/docs/live-acceptance.md).
