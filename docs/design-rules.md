# Design rules

The canonical DR-001–DR-008 policy now belongs to **Viewrule**:
[design-rules.md](https://github.com/lanej/viewrule/blob/main/docs/design-rules.md).
It ships inside the installed package and is embedded in each report, so rule
citations retain the wording used for that run.

The policy is our interpretation inspired by Edward Tufte's *The Visual Display
of Quantitative Information*, not quotations or universal numerical thresholds.
Personal preferences stay in `claude/ui-review/preferences.json` and application
constraints stay in each app's `.ui-review/rules.json`.

See [installation and local development](ui-review.md). The upstream link becomes
available after initial publication.
