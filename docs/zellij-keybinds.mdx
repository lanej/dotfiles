**Press Ctrl-f, release it, then press the next key.** Uppercase letters require Shift. These are my dotfiles bindings, not Zellij's default shortcuts.

Most commands return immediately to your application. **Esc**, **Enter**, or **Ctrl-c** cancels the prefix. **Ctrl-f p** and **Ctrl-f Ctrl-p** do different things.

## Panes

| Key after Ctrl-f | Action |
| --- | --- |
| `h` / `Left` | Focus left |
| `j` / `Down` | Focus down |
| `k` / `Up` | Focus up |
| `l` / `Right` | Focus right |
| `Tab` / `o` | Focus the next pane |
| `;` | Focus the last-focused pane |
| `s` / `"` | Split below in the current directory |
| `v` / `%` | Split right in the current directory |
| `z` | Zoom or restore the focused pane |
| `Z` | Zoom or restore without the surrounding UI |
| `x` | Close the focused pane and its program |
| `J` / `K` | Move the pane down / up within the tab |
| `!` | [Move the pane directly to a new tab](zellij/move-pane.mdx) |
| `m` | [Choose a new or existing destination tab](zellij/move-pane.mdx) |
| `M` | [Gather all live panes into an existing tab](zellij/gather-panes.mdx) |

Bare **Ctrl-h/j/k/l** moves through Neovim splits before crossing into Zellij. Prefixed **Ctrl-f h/j/k/l** moves between Zellij panes directly. See [smart navigation](zellij/smart-navigation.mdx).

**Closing is not detaching.** `x` ends the pane's program without an extra confirmation. `d` leaves the session running.

## Tabs

| Key after Ctrl-f | Action |
| --- | --- |
| `c` | Create a tab |
| `n` / `Ctrl-n` | Go to the next tab |
| `Ctrl-p` | Toggle to the last-focused tab |
| `Ctrl-f` | [Open the tab picker with pane previews](zellij/tab-picker.mdx) |
| `0`–`9` | Select the first through tenth tab by position |
| `r` / `,` | Rename the tab; Enter saves, Esc or Ctrl-c cancels |
| `W` | [Swap this tab with a selected tab](zellij/tab-swap.mdx) |

Modern [tab positions](zellij/status-bar.mdx) start at **0**, independently of numbers in tab names. **Ctrl-p** toggles recent tabs; it does not mean the previous numeric position.

## Resize and layouts

| Key after Ctrl-f | Action |
| --- | --- |
| `<` / `>` | Grow toward the left / right |
| `+` / `-` | Grow toward the top / bottom |
| `Ctrl-r` | Enter repeatable Resize mode |
| `=` | [Equalize the focused pane's aligned row or column](zellij/equalize.mdx) |
| `g` | [Apply golden-ratio sizing to the left pane](zellij/golden-ratio.mdx) |
| `G` | Apply golden-ratio sizing even past its width guard |
| `Space` | Cycle forward through layouts |
| `Ctrl-o` | Cycle backward through layouts |

Layout cycling offers columns, rows, stacked, and equalize. The [equalize layout](zellij/equalize.mdx#choose-a-layout-instead) can rearrange panes; direct **Ctrl-f =** balances an existing aligned group.

## Keys inside modes

Enter a mode once, then use bare keys. In Scroll and Search modes, **Ctrl-f** pages down rather than starting another prefix command.

### Resize mode: Ctrl-f Ctrl-r

| Key | Action |
| --- | --- |
| `h/j/k/l` or arrows | Grow left/down/up/right |
| `H/J/K/L` | Shrink from left/down/up/right |
| `=` / `+` | Increase size |
| `-` | Decrease size |
| `Esc` / `Enter` / `Ctrl-c` | Return to the application |

For example, **Ctrl-f Ctrl-r**, **h**, **h**, **Enter** grows left twice, then exits. `=` inside this mode means increase size, not equalize.

### Scroll mode: Ctrl-f [

| Key | Action |
| --- | --- |
| `j` / `Down`, `k` / `Up` | Scroll down / up |
| `Ctrl-f` / `PageDown`, `Ctrl-b` / `PageUp` | Page down / up |
| `d` / `Ctrl-d`, `u` / `Ctrl-u` | Half-page down / up |
| `g` / `Home`, `G` / `End` | Top / bottom |
| `[` / `]` | Previous / next shell prompt |
| `/` / `s` | Enter a search query |
| `m` | Select the command at the scroll position |
| `y` | Copy an existing selection and return |
| `c` | Copy the last command output and return |
| `e` | Open scrollback in Neovim |
| `Esc` / `Enter` / `q` / `Ctrl-c` | Return to the application |

Prompt jumps and command copying depend on support from the running application. `y` does not begin arbitrary visual selection; use **e** to select text in Neovim.

### Search entry and Search mode: Ctrl-f /

Type a query and press **Enter**. **Esc** or **Ctrl-c** while entering the query returns to Scroll mode.

| Key in Search mode | Action |
| --- | --- |
| `n` | Next match downward |
| `N` / `p` | Previous match upward |
| `j` / `Down`, `k` / `Up` | Scroll down / up |
| `Ctrl-f` / `PageDown`, `Ctrl-b` / `PageUp` | Page down / up |
| `/` | Clear the query and enter another |
| `c` | Toggle case sensitivity |
| `w` | Toggle wrapping |
| `o` | Toggle whole-word matching |
| `e` | Open scrollback in Neovim |
| `Esc` / `Enter` / `q` / `Ctrl-c` | Return to the application |

`c` changes search options here; it does not copy command output.

### Other modes

Move and Tab modes have no direct prefix shortcut. To enter them deliberately, run `zellij action switch-mode move` or `zellij action switch-mode tab` in a terminal.

| Mode | Keys | Action |
| --- | --- | --- |
| Move | `h/j/k/l` or arrows | Move the pane left/down/up/right |
| Move | `Tab` / `n`, `p` | Move the pane forward / backward |
| Move | `[` / `]` | Move the pane into a tab on the left / right, then exit |
| Tab | `h` / `Left`, `l` / `Right` | Move the tab left / right |
| Both | `Esc` / `Enter` / `Ctrl-c` | Return to the application |

**Ctrl-f m** opens the destination picker; it does not enter Move mode. **Ctrl-f W** opens the swap picker, not Tab mode.

## Shared popup keys

The [shared popup](zellij/shared-popup.mdx) uses the same keymap, including navigation, splits, tabs, copying, and search. Its one difference is **Ctrl-f P**: inside the popup, that key hides the view. **Ctrl-f d** also detaches the view without stopping its shells.

## Legacy configuration

If your installed keys differ, you may be using the older configuration. Modern-only features need the managed modern Zellij installation described in [getting started](zellij.md#start-a-session).

| Area | Modern | Legacy |
| --- | --- | --- |
| Tab positions | Start at 0 | Start at 1; `0` and `1` both choose the first tab |
| Session creation / rename: `C` / `w` | Direct actions | Open the session manager |
| Balance / golden ratio: `=` / `g` / `G` | Available | Unbound |
| Local attention: `a` / `Ctrl-a` | Direct jump / cycle | Unbound |
| Inbox / history / watch / mute: `b` / `B` / `A` / `U` | Available | Unbound |
| Session card: `I` | Available | Unbound |
| Client chooser: `D` | Available | Unbound |
| Session paste: `p` | Available | Unbound |
| Gather panes: `M` | Available | Unbound |
| Scrollback editor: `e` | Keeps terminal colors | Plain text |
| Mouse interaction | Disabled | Enabled |

The legacy configuration still assigns `m` and `W`, but their custom pickers require a modern installation. A key appearing in a configuration is not a guarantee that its feature is available on an older runtime.

## tmux habits that do not transfer

- **Cross-session pane movement:** `m`, `M`, and `!` move panes between tabs in this session only. `H` and `S` are unbound.
- **Reload shortcuts:** `R`, `Ctrl-l`, and `*` are unbound.
- **Timed repeats:** use **Ctrl-f Ctrl-r** for repeated resizing. Most other prefix commands return immediately to the application.
- **Stock Zellij defaults:** use this map rather than the upstream default shortcut sheet.
