## Configure first. Install deliberately.

<div className="workflow">

`make base` initializes the native baseline. `make bootstrap` provisions uv and Python. `make plan` shows the selection. `make install` installs the selected tools and applies their configuration.

After setup, `make` reapplies the resolved configuration without installing packages. [Follow the installation guide](../README.md#installation) for prerequisites and machine settings.

</div>
