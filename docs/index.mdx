## Quick start

Copy this one-liner to clone the repository, initialize the native OS configuration, and install uv and Python:

```sh
curl -fsSL https://raw.githubusercontent.com/lanej/dotfiles/master/install.sh | sh
```

Requires Git, Make, and Bash on macOS or Linux. An existing `~/.files` checkout is reused without pulling updates or changing branches. [Read the installer](../install.sh) before running it.

Then [choose this machine’s tool sets](../README.md#configuration-sets) in `~/.config/dotfiles/config.toml`, for example `workstation` for the broad setup. From the checkout, preview and install that selection:

```sh
make plan && make install
```

## Configure first. Install deliberately.

| Command | What it does |
| --- | --- |
| `make base` | Create a missing machine configuration and link the native OS baseline. |
| `make bootstrap` | Apply the native baseline and provision uv and Python. |
| `make plan` | Show the tools and configuration selected by this machine’s settings. |
| `make install` | Install the selected tools and apply their configuration. |

After setup, `make` reapplies the resolved configuration without installing packages. [Follow the installation guide](../README.md#installation) for prerequisites and machine settings.
