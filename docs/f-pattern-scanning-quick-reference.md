# F-pattern scanning: quick reference

Maximize understanding per reader effort. Support observed scanning, not a literal F shape.

- Lead with the outcome or required action.
- Start paragraphs and list items with meaningful words.
- Order information by reader priority; keep steps in execution order.
- Separate focused paragraphs with whitespace.
- Choose text or visuals for clarity: screenshots for appearance, diagrams for structure, charts for patterns.
- Use prose for reasoning, lists for independent points, tables for comparisons.
- Use headings only for navigation; omit empty scaffolding.
- Bold key labels or facts sparingly.
- Keep visuals factual; preserve units, scope, sources, and caveats.
- Keep consequential caveats beside their claims.
- Link supporting evidence descriptively.

Preview rendering. Scan the opening, headings, labels, and first words for outcome and action. Check caveats, then read fully.
