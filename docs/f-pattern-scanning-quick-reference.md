# F-pattern scanning: quick reference

Support observed scanning of left-to-right prose; do not manufacture a literal F shape.

- Lead with the outcome or required action.
- Start paragraphs and list items with meaningful words.
- Order information by reader priority; keep steps in execution order.
- Give each paragraph one focus; separate ideas with whitespace.
- Use prose for reasoning, lists for independent points, tables for comparisons.
- Add descriptive headings only when navigation needs them; omit empty scaffolding.
- Bold key labels or facts sparingly.
- Keep consequential caveats beside their claims.
- Use descriptive links beside supporting claims.

Preview rendering. Scan opening, headings, labels, and first words for outcome and action. Check caveats and spacing, then read the complete text.

Read the [full specification](f-pattern-scanning.md) only for rationale, research, expanded examples, ambiguous layout tradeoffs, or recurring readability problems.
