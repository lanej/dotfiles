Both multiplexers use **Ctrl-f** as the prefix and Vim-style pane navigation. Zellij is an opt-in trial; familiar keys do not imply identical copy behavior.

## Copying is a deliberate difference

| Task | tmux | Zellij |
| --- | --- | --- |
| Select arbitrary text | Inline Vim-style copy mode | Open scrollback in Neovim with **Ctrl-f e** |
| Select a region | tmux copy-mode selection | Neovim **v**, **V**, or **Ctrl-v**, then **y** |
| Paste the multiplexer copy | **Ctrl-f p** pastes the tmux buffer | **Ctrl-f p** pastes the session’s last Neovim yank |
| Paste the system clipboard | Terminal paste shortcut | Terminal paste shortcut |

In Zellij, `:q!` leaves the scrollback editor and returns to the original terminal. **Ctrl-f p** pastes text yanked in that editor. Mouse selection and native command-copy actions do not replace that saved text.

Clipboard copying depends on your terminal's settings, including over SSH. Use the [copy and paste guide](./zellij/copy-paste.mdx) for selection, buffer lifetime, and the distinction between session text and the system clipboard.

## Start and return to work

For a configured Zellij installation:

```sh
zellij attach --create main
```

**Ctrl-f d** detaches while keeping the session running. In a new shell, `zj main` is the short form. See the [Zellij guide](./zellij.md) to get started and choose a custom feature.

For tmux, `tmux-sessions list` shows saved snapshots and `tmux-sessions restore` opens the restore picker. Restoration asks for confirmation. See the [session guide](./tmux.md) for persistence and agent status.
