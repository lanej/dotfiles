# Coordinator lessons

- **Verify before reporting.** Reports can describe an earlier assignment. Read the current task before resuming the worker and verify the remote result before reporting a merge.
- **Authority is human.** Record the operator’s scope and limits in the worker brief. Return to the original instruction if the requested effect is unclear.
- **Conflicts need project context.** Bring Octo Manager’s feedback to the owning worker, apply the target repository’s guidance and review the assembled change.
- **Preserve before handoff.** Confirm that the receiving worker can access the checkout, uncommitted work and outstanding follow-ups before retiring the previous session.
